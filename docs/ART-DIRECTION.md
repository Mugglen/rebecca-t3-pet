# 瑞贝卡桌宠美术规格

用户已确认：角色为《赛博朋克：边缘行者》瑞贝卡，Q 版动漫风，用于 T3 Code 状态监控。以下比例、动作和导出参数是本项目的实现建议；不是用户逐项指定，也不是官方桌宠设计。

参考库见 [INDEX](../references/INDEX.md) 与 [manifest](../references/manifest.json)。参考图已保存本机；运行角色须单独制作。

## 识别特征

1. **薄荷绿双马尾**，中分／近心形额前发线，发束内侧青绿色阴影；头顶深蓝发箍，两侧深蓝机械形发饰带荧光绿条。
2. **浅冰蓝肤色**，两眼外下侧有细短的机械折线；紫色唇线可在小尺寸简化保留。
3. **多层霓虹眼睛**：珊瑚红／粉红外部、绿黄环形、紫粉中心与浅色高光。不能简化成普通单色红眼而丢掉核心识别点。
4. **宽大深蓝外套**，立领、厚袖和肩部装甲块，袖口与下摆的荧光绿细边。轮廓是“上半身蓬松、下方短腿”，不是紧身连衣裙。
5. **粉色颈部纹样**及一侧大腿的粉色符号；纹样在小尺寸用清晰色块与少量折线表达。
6. 强化机械手版本采用一粉一蓝的大手和黄绿色指关节圆点。正面图中画面左侧粉色、右侧蓝色；转换视角时保持角色左右关系，不通过任意整图镜像改变配色。
7. 深蓝鞋配荧光绿带／鞋边。双马尾、双手和鞋完整可见，避免裁切。

这些观察以 [CDPR 角色页](https://www.cyberpunk.net/en/edgerunners)、[官方 Cosplay Guide 第 3–7 页](https://cdn-s-cyberpunk.cdprojektred.com/cosplay-guides/REBECCA_COSPLAY_GUIDE_EN.pdf#page=3) 为身份基准，Q 版比例参考 [Nendoroid](https://www.goodsmile.com/en/product/12203/Nendoroid%20Rebecca)。

## Q 版转译

- 建议总高约 2.3–2.7 头身，头部稍大，四肢短但关节与手势可读。Nendoroid 参考用于比例与表情，不复制其塑料材质、底座或摄影背景。
- 使用清晰动漫线条、平涂与少量赛璐璐阴影；保持薄荷、深蓝、粉、蓝、荧光绿五个主要色区。
- 深蓝外轮廓和明亮肤色形成主体对比；透明背景上不要附带黄色海报底、地台或商品支架。
- 主显示高度建议 220–280 DIP；在 160 DIP 小尺寸仍应识别双马尾、外套和眼睛。高分辨率原稿再缩放，不从网页缩略图直接抠图作为成品。
- 待机采用友善而得意的神情。提醒采用招手或指向提示牌；运行采用专注操作小终端；无需用枪口指向用户来表达普通状态。
- 已存在普通手与强化机械手两套官方形象；本项目建议统一使用强化机械手版本，整组素材不要随机切换。

## 状态与动作

| 状态 | 角色姿态 | 小尺寸表达 |
| --- | --- | --- |
| idle | 放松站立，轻呼吸、偶尔眨眼 | 头发和肩部小幅移动 |
| running | 双手操作小终端、专注眼神 | 节奏平稳，终端轻闪但不频闪 |
| needs-attention | 单手招呼、指向提示牌 | 明确招手，与运行状态可同时显示角标 |
| completed | 得意笑、握拳或短暂 V 手势 | 仅状态转换触发，随后恢复当前状态 |
| failed | 皱眉看警示牌 | 不持续抖动，不只依靠红色区分 |
| stopped | 放下手、短暂摊手 | 与成功庆祝不同 |
| disconnected | 拿起断开的连接头／查看信号 | 清楚表达无法读取状态 |
| incompatible | 看着带问号的小终端 | 文本说明版本／数据不兼容 |

参考动作：Nendoroid 图 04 的双拳适合完成反馈；BUZZmod 图 09 的坐姿适合安静待机；官方头部页用于表情一致性。[Aniplex / Good Smile 动作参考](https://www.goodsmile.com/en/product/1140950/%2BBUZZmod.%2BCyberpunk%2BEdgerunners%2BREBECCA%2B1%2B12%2Bscale%2Baction%2Bfigure)

## 资产接口与验收

- 首个角色母版：透明 RGBA PNG，建议不低于 1024×1024，角色全身，四周保留安全边距。
- 多状态图使用同一画布、同一脚底锚点和一致角色大小；不要每次切换时跳位置。
- 原始生成／绘制结果单独留存；每个导出图记录来源母版与加工步骤。透明度必须真实，不是画出的棋盘格。
- 若首版采用静态母版加整体位移动画，应明确称为“整体动效”，不能称为已完成逐帧骨骼动画。
- 生成多帧后逐帧检查发饰、眼睛、机械手配色、衣服边线、手指数与脚底锚点，避免身份漂移。
- 在浅／深桌面背景和目标显示尺寸检查轮廓与文字气泡；提示文本在 UI 绘制，不烧进角色图。
- 安静模式停止循环位移和发光变化，状态提示仍可读。
