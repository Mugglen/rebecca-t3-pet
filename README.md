# 瑞贝卡 · T3 桌宠

一个以《赛博朋克：边缘行者》瑞贝卡为角色的 **Q 版动漫风 T3 Code 状态桌宠**。

让用户不用一直盯着 T3 Code 窗口，也能从角色的动作和简短提示了解：任务正在运行、需要回应、刚刚完成，或者出现异常。

## 当前进度

项目初始化阶段，已创建独立 Git 仓库并注册到本机 T3 Code 项目列表。已经确认产品方向，并开展本机状态来源核对。**目前还没有可运行的桌宠、角色成品或启动程序。**
